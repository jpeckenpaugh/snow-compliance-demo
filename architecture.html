Compute

Warehouses

WarehouseSizeAuto-suspendUsed for
WH_LOADX-Small60sIngest / generation (build only)
WH_ANALYTICSX-Small60sDemo queries and reporting

X-Small with 60-second auto-suspend keeps an idle demo effectively free. The dataset is tiny (well under a gigabyte), so compute, not storage, is the only cost lever.

Access

Role model

ACCOUNTADMIN
  SYSADMIN
    DEMO_ADMIN          -- builds RAW/CORE/MARTS
    COMPLIANCE_ADMIN    -- owns SECURITY schema (policies, masks, mapping)
    ATTORNEY            -- matter-scoped reads via row access policy
    PARALEGAL           -- matter-scoped reads, reduced columns
    AUDITOR             -- reads GOV audit views; no data mutation
Principle Administrators never use ACCOUNTADMIN for demo work. Analysts never see unfiltered matter data. Policy objects live in SECURITY and are owned by COMPLIANCE_ADMIN, not by whoever builds the tables.
Delivery

Deployment & environments

  • Snowflake: scripts in sql/ run in order; ingest/ scripts populate data. Idempotent (CREATE OR REPLACE, MERGE) so the demo can be rebuilt from scratch.
  • Review site: this repo. GitHub Pages serves main:/ — any push to main republishes automatically. It is the staging surface for board review.
  • Secrets: Snowflake credentials are stored as Paperclip secrets and injected at run time — never committed to this repo or pasted into documents.
